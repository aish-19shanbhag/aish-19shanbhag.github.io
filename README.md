# aish-19shanbhag.github.io

Personal portfolio site for Aishwarya Ramanath Shanbhag — Data Scientist specializing in fraud detection and financial crime risk analytics.

**Live site:** https://aish-19shanbhag.github.io

Built with plain HTML/CSS, no framework or build step. Fonts via Google Fonts (Source Serif 4, IBM Plex Mono).

## Structure

```
├── index.html          # entire site
├── resume/              # resume PDF, linked from the site
└── README.md
```

## Updating

Edit `index.html` directly, commit, and push to `main`. GitHub Pages rebuilds automatically within a minute or two.
